# Look & Feel

## Theme
- **Modern with historic touches** — the app serves as a tourism guide for the city of Heidelberg
- Reflect Heidelberg's rich history through subtle design choices: typography, color palette, decorative elements
- Keep the overall layout clean and contemporary

## Color & Mode
- **Light mode only** — do not implement dark mode upfront
- Use a warm, inviting color palette that evokes Heidelberg's sandstone architecture and natural surroundings

## Typography & Style
- Use readable, modern fonts with optional serif accents for historic character
- Tailwind CSS for all styling — no custom CSS frameworks
- Responsive design as a baseline

## Imagery & Icons
- Prefer subtle, elegant iconography
- Any decorative elements should hint at Heidelberg's landmarks (castle, old bridge, Neckar river) without being heavy-handed
- **Do not create custom icons** — use well-established, free icon libraries (e.g., Lucide, Heroicons, Feather Icons, or similar high-popularity open-source sets from GitHub)
- Download and serve icon assets locally, consistent with the self-contained approach
